# Traço Cru Design — V15.3

Site estático editorial para um ateliê de arte em cimento. A escultura do Hero é uma **fotografia original**, não um modelo 3D ou vídeo.

## Executar localmente

```bash
cd traco-cru-design-site
python3 -m http.server 8000
```

Abra <http://localhost:8000>.

Arquivos centrais: `index.html`, `styles.css`, `main.js` e `assets/`.

Leia `ALTERACOES-V15.3.md` para o resumo das melhorias de responsividade e testes. Leia `PENDENCIAS-PUBLICACAO.md` antes de colocar o site no ar.

A V15 não inventa preços, depoimentos, informações das peças, datas de cursos ou endereço. O formulário **não envia dados**: apenas prepara uma mensagem para copiar e colar no Instagram.

Versão V15.4: palavras monumentais do Hero à frente da fotografia (ver `ALTERACOES-V15.4.md`).
